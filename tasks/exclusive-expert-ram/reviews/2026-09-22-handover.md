12. HARNESS GOTCHAS LEARNED TODAY (save a successor the rediscovery)
    - measure.sh hardcodes PROBE_PASSES=2 (line ~186); env cannot override.
    - Pass 1 at >=32K is contaminated by the serial expert-bank build

    - NOISE FLOOR: two arms doing provably identical work (reserve 3E vs 2E,
      same swaps/rates) differed 8.7% in decode at 80K. Do not claim a
      decode win below ~9% from a single arm pair.
    - measure.sh builds a per-arm env file and STRIPS the knobs the sweep
      owns from the host's serve.env. New knobs need BOTH a write and a
      strip entry, else a stray value in the owner's file silently applies
      to every arm. FT_RESERVE and FT_TIEBREAK were added this way.
    - measure.sh runs `set -euo pipefail`: never end a block with
      `[ -n "$X" ] && echo ...` — use an `if`, or arms without that var
      abort.
    - sweep-ornith.sh had no FT_SIZES, so it would have stopped at 80K and
      never probed 256K in all six arms. Now sets 8000 32000 80000 200000
      256000.
    - FT_POST runs a command while the server is still UP (used for
      long_gen.py / recall.py). FT_POST_TIMEOUT default 3600.
    - long_gen.py stores only the first/last 600 chars of the answer, so
      output comparison is head+tail+lengths, not a full byte diff.

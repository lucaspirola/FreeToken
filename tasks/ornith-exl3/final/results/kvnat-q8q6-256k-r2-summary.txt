Let me extract the main design decisions:

**Architecture/serve model:**
- Hybrid Mamba-2 (SSD) + full-attention + latent MoE. Mamba-2 recurrent state is fp32 (required by kernels), ~47 MiB/seq on Lightning, ~160 MiB/seq on Super.
- Super is `single_stream_only` (bs=1 decode graph, --max-running-requests 1).
- Lightning is NOT single_stream_only: up to 16 concurrent.

**MoE offload strategy:**
- `--moe-backend offload` is the recommendation. Experts live in host RAM (NVFP4 banks), fetched over PCIe on demand.
- NVFP4 expert banks: 15.4 GiB on Lightning.
- `--moe-pageable-gpu` for WSL pin-budget overflow.
- `FREETOKEN_PIN_BUDGET_GB=17` pins every layer, keeps CUDA graphs.

**NVFP4 expert GEMM backend:**
- `triton` is the default and recommended. b12x (tensor-core) is wrong on this geometry. flashinfer can combine with kv-grow-step. marlin rejected at config time.
- Chosen once at bank-load time because it pins the on-GPU weight layout.

**KV cache:**
- `q8_0` quantized KV chosen over fp8_e4m3 (fp8 flipped first tokens on cached-prefix reuse).
- Growable KV via `--kv-grow-step-tokens` funds KV from expert cache.
- Context ceiling: tokenizer model_max_length 262144 (though max_position_embeddings is 1M).

**Concurrency / state pool:**
- `--linear-state-slots` sizing for Mamba-2 ping-pong state. `4·mr + 1` for hybrid_radix.
- Fixed 16-lane launch sizes GDN state pool for max-running-requests up front.

**Expert cache policy:**
- LFU above ~15% miss rate, LRU below. At bs=16, LRU degenerates to 99.6% miss, LFU halves to 51%, worth 1.80× throughput.

**CUDA graphs:**
- Dense decode graph ladder [1..16] for offload-MoE (padded rows route their own experts, so sparse is slower).
- Decode CUDA graphs disabled with pageable-gpu.

**Prefill:**
- `--max-prefill-length 8192`. Chunk size not a throughput lever.
- MoE prefill GEMM optimizations: per-block scale loading (1.73x), native FP4 decode, deinterleaved A operand.

**Speculative decoding:**
- `--speculative ngram`, off by default, greedy/single-stream only.
- `--spec-ngram-n 8`, `--spec-draft-len 8`, `--no-spec-adaptive`.
- Extend-path MoE fix (`--moe-extend-cache-tokens 64`) was the blocker.
- Long context regresses.

**1M single-session profile:**
- Session spill to RAM then NVMe.
- Look-ahead promotion, partial-prefix restore, prefill-time state capture.
- One resident session, others queue.

**Memory prediction:**
- `--memory-ratio 1.00` default, predicted from config, measured at startup.

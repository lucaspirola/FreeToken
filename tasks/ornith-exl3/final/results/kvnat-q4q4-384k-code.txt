## Design

### Core LRU Cache with TTL

I'll use `OrderedDict` for the LRU ordering (Python 3.7+ dicts maintain insertion order, but `OrderedDict` has convenient methods like `move_to_end` and `popitem(last=False)`).

Thread safety: I'll use a `threading.Lock` (or `RLock`) to protect all mutations and reads.

TTL: Each entry stores a value plus an expiration timestamp. I'll use `time.monotonic()` for expiration to avoid issues with system clock changes. Actually, for TTL, monotonic is the right choice because it's not affected by system clock adjustments.

Size-based eviction: When the cache exceeds `max_size`, evict the oldest (LRU) entry.

Statistics: Track hits, misses, and compute hit rate.

Let me think about the expiration check. When accessing an entry, if it's expired, treat it as a miss and remove it.

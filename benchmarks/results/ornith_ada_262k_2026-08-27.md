# Ornith 262K benchmark — RTX 2000 Ada

Date: 2026-08-27  
FreeToken commit under test: 770b572b13cc44a3ffb6795eab04bc6d87727c62  
Host: NVIDIA RTX 2000 Ada Generation under WSL  
Mode: one concurrent request, CUDA graph batch 1, LFU expert cache, 0.97 memory ratio,
8,192-token prefill chunks, full 262,144-token KV pool.

## Method

Both checkpoints processed the same cold RULER niah_single_1 sample through
/v1/completions. The source sample contains 272,843 Ornith tokens, so
bench_long_context.py removed only repetitive filler to reach 261,800 prompt tokens
while preserving the leading instruction, hidden needle, and trailing question. Each
run issued exactly one expensive prompt request; there was no full-prompt warm pass.

The expected needle was 5663623. Greedy decoding and ignore_eos=True were used so
the post-prefill decode window had a fixed requested length. Both models recovered the
needle and answered it explicitly before any ignored end-of-sequence marker.

## Results

| Checkpoint | KV cache | Prompt | Cold TTFT | End-to-end prefill | Decode window | Full-context decode | Needle |
|---|---:|---:|---:|---:|---:|---:|---:|
| Ornith-1.5-35B-Q4_K_M | INT4 | 261,800 | 1,044.213 s | 250.72 tok/s | 126 inter-token steps | 29.27 tok/s | PASS |
| Ornith-1.5-35B-Q6_K | Q8_0 | 261,800 | 1,103.842 s | 237.17 tok/s | 126 inter-token steps | 22.28 tok/s | PASS |

At this near-full context, Q6_K + Q8_0 is 5.40% slower in prefill and 23.88% slower
in decode than Q4_K_M + INT4. Equivalently, Q4_K_M + INT4 is 5.71% faster in prefill
and 31.37% faster in decode. Both configurations retained 0.43 GiB free after CUDA
graph capture and completed without OOM, illegal memory access, retry, or scheduler
failure.

  --cache-policy lfu --json /tmp/ornith_final_q6_q8_262k.jsonl
~~~

## Final tuning decisions

- Keep the 0.97 memory ratio. A 0.98 screen reduced post-graph headroom to 0.28 GiB
  for a Q6 decode change within run variance (45.32 to 45.56 tok/s).
- Keep 8,192-token prefill chunks. An actual 16K-prompt screen completed in 29.37 s
  with 8K chunks; a single 16K chunk made no progress for 160 seconds and was rejected.
- Keep LFU and prefill overlap enabled.
- Keep prefill-hit D2D seeding disabled; it regressed the measured decode gate.
- Do not use speculative/MTP decoding for these production paths.
- The Q4 compact mixed-size cache now reinvests its saved VRAM: 5,304 decode slots
  instead of 4,953, improving the paired short full-pool gate from 57.91 to
  61.39 tok/s with an identical output hash.
